## AUTH APIs (Donon apps ke liye)
----------------------------------------------------

### 1. Register (Patient signup)
- POST ?module=auth&action=register
- Body: name, email, password, phone, gender, date_of_birth, device_token
- Returns: token + user data

### 2. Login (Donon apps ka login)
- POST ?module=auth&action=login
- Body: email, password, device_token, device_type, device_name
- Returns: token + user data (role se pata chalta hai kaun si app hai)

### 3. Logout
- POST ?module=auth&action=logout
- Auth: Yes
- Token delete karta hai

### 4. Forgot Password
- POST ?module=auth&action=forgot-password
- Body: email
- Email bhejta hai password reset link ke sath

### 5. Profile Dekhna / Update Karna
- GET ?module=auth&action=profile → Profile data
- PUT ?module=auth&action=profile → Update (name, phone, profile_image)
- Auth: Yes

----------------------------------------------------
## PATIENT APIs (Patient App ke liye)
----------------------------------------------------

### 6. Patient Dashboard
- GET ?module=patient&action=dashboard
- Auth: Yes
- Returns: upcoming appointments, prescriptions, stats

### 7. Dentist Dhundhna (Find Dentists)
- GET ?module=patient&action=dentists
- Params: search, specialization, page
- Auth: Yes
- Saare available dentists dikhata hai filter ke sath

### 8. Appointment Book Karna
- GET ?module=patient&action=appointments → Saari appointments
  - Params: status, history (1 for past), page
- POST ?module=patient&action=appointments → Nai appointment book
  - Body: dentist_id, treatment_id, appointment_date, start_time, end_time, notes
- PUT ?module=patient&action=appointment/{id} → Reschedule
  - Body: status
- DELETE ?module=patient&action=appointment/{id} → Cancel
- Auth: Yes

### 9. Medical Records Dekhna
- GET ?module=patient&action=medical-records
- Auth: Yes
- Apna pura medical history dikhata hai

### 10. Prescriptions Dekhna
- GET ?module=patient&action=prescriptions
- Params: page
- Auth: Yes
- Saari prescriptions dikhata hai doctor ki taraf se

### 11. Payments Karna / Dekhna
- GET ?module=patient&action=payments → Payment history
- POST ?module=patient&action=payments → Online payment
  - Body: invoice_id, amount, gateway (stripe/jazzcash/easypaisa), notes
- Auth: Yes

### 12. Treatment Progress Dekhna
- GET ?module=patient&action=treatment-progress
- Params: plan_id (optional)
- Auth: Yes
- Treatment plan ka progress dikhata hai

### 13. Patient Notifications
- GET ?module=patient?action=notifications
- Auth: Yes

### 14. Patient Chat
- GET ?module=chat&action=conversations → Chat list
- POST ?module=chat&action=conversations → Nai conversation
  - Body: dentist_id
- GET ?module=chat&action=messages/{id} → Messages
- POST ?module=chat&action=messages → Message bhejo
  - Body: conversation_id, message, message_type, file_path
- POST ?module=chat&action=read → Read mark karo
  - Body: conversation_id
- Auth: Yes

### 15. Patient File Upload
- POST ?module=upload&action=image → Profile photo
  - Body: file (JPEG/PNG/GIF/WEBP, max 5MB)
- POST ?module=upload&action=file → Medical file
  - Body: file (PDF/DOC/DOCX/JPEG/PNG, max 10MB), patient_id, type (xray/report/prescription/image/document/other), title
- GET ?module=upload&action=list → Files list
  - Params: patient_id, type
- Auth: Yes
